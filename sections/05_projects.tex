\projectHeading
{Kubernetes R\&D Migration Lab for Distributed Erlang SMS Firewall}
{Omobio R\&D / Lab}

\begin{itemize}

\item Built a Kubernetes lab proof of concept to evaluate containerizing a multi-node
distributed Erlang SMS Firewall architecture, using StatefulSets for stable application
identities and Flannel for cluster networking.

service discovery, restart behavior, and operational considerations across firewall and
logging components in a three-node lab cluster.

\item R\&D-only prototype used for technical evaluation; it was not deployed to a
customer or production environment.

\end{itemize}
